# TPI-PROGRAMACIÓN1-GESTIÓN_DE_PAÍSES
## Trabajo práctico Integrador - Programación 1 - Gestión de Datos de Países en Python: filtros, ordenamientos y estadísticas. 
El objetivo del proyecto es desarrollar una aplicación en Python que permita 
gestionar información sobre países, aplicando listas, diccionarios, funciones, 
estructuras condicionales y repetitivas, ordenamientos y estadísticas.
La aplicación carga y lee datos desde un archivo CSV y realiza consultas en base a esa 
información.
